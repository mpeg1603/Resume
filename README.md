# Resume — интерактивное резюме Владимира Болкунова

Одностраничный сайт-резюме на GitHub Pages. Два режима:

1. **Игра «Текстовый раннер»** — динамичная 2D-игра (вид сбоку, автобег):
   предложения и фразы резюме становятся платформами, по которым ты бежишь.
   Один тап / пробел = прыжок; пробежал по платформе — фраза «прочитана».
   Пять уровней соответствуют секциям резюме: Обо мне → Фриланс C# → Unity → Вайбкод → ИИ-инструменты.
2. **Читаемая страница резюме** — оформленное CV с навыками, опытом и видео.

В конце игры — ссылка на страницу резюме.

## Как устроен сайт

- Vanilla HTML/CSS/JS + Canvas — без npm, билда и зависимостей.
- Один `index.html` с hash-роутингом: `#/` (лэндинг), `#/game`, `#/resume`.
- Текст резюме — единый источник в [`assets/js/data.js`](assets/js/data.js):
  его используют и страница резюме, и игра (фразы-платформы).

```
Resume/
├── README.md                     # этот файл
├── .gitignore
├── index.html                    # SPA: роутер + три экрана
└── assets/
    ├── css/style.css             # тёмная тема, mobile-first
    └── js/
        ├── data.js               # резюме + фразы-платформы (единый источник)
        ├── router.js             # #/, #/game, #/resume
        ├── welcome.js            # лэндинг с двумя кнопками
        ├── resume.js             # страница резюме + видео
        └── game/
            ├── engine.js         # цикл, физика прыжка, ввод (тап / пробел)
            ├── level.js          # платформы из фраз data.js
            └── hud.js            # прогресс, пауза, финал со ссылкой на резюме
```

## Деплой

GitHub Pages: Settings → Pages → branch `main`, root `/`.
Push в `main` = автоматическое обновление сайта.
